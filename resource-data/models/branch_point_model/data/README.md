Artificial data for the model `branch_point_model`
------------------------------------------------------

Data files generated by the script `../matlab/branch_point_model_make_data.m`:

* `artificial_network_true.tsv`: network structure and true kinetic constants (SBtab)
* `artificial_kinetic_data.tsv`: artificial kinetic data (SBtab, table ParameterData)
* `artificial_state_data.tsv`: artificial metabolic state data: fluxes, metabolite concentrations, enzyme concentrations (SBtab)

These files are used as example input files in the demo script `model-balancing/demo/demo_cmb_experimental_data.m`.
